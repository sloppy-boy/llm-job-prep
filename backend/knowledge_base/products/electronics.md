# 电子商品规格说明

本页汇总云选商城在售主力电子商品的规格参数与适用场景，帮助您在购买前确认是否匹配需求。具体参数以商品包装/官方页面为准，平台展示数值存在行业允差（约 ±5%）。

## 一、智能音箱

| 参数 | X1 标准版 | X1 Pro 尊享版 |
|------|----------|--------------|
| 扬声器 | 5W 单单元 | 10W 双单元（立体声） |
| 蓝牙 | 5.0 | 5.3 |
| 连接方式 | Wi-Fi + 蓝牙 | Wi-Fi 6 + 蓝牙 + AUX |
| 语音助手 | 云选小优 | 云选小优（支持方言识别） |
| 供电 | 有线供电 | 内置 4000mAh 电池，续航约 8 小时 |
| 尺寸 | 98 × 98 × 120mm | 120 × 120 × 180mm |
| 适用面积 | ≤ 30㎡ | ≤ 60㎡ |

**适用场景**：卧室、书房听音乐；智能家居语音控制；儿童睡前故事（需配合内容会员）。

| 参数 | E1 半入耳 | E2 入耳主动降噪 |
|------|----------|----------------|
| 单次续航 | 5 小时 | 6 小时 |
| 总续航（含充电仓） | 25 小时 | 30 小时 |
| 降噪 | 无 | -38dB 主动降噪 |
| 防水 | IPX4 | IPX5 |

**适用场景**：通勤地铁（E2 降噪）；运动跑步（IPX5 防汗）；办公会议通话（双麦通话降噪）。

## 三、充电宝

| 参数 | P1 超薄款 | P2 大容量款 |
|------|----------|------------|
| 容量 | 10000mAh | 20000mAh |
| 输出 | 18W 单口 | 22.5W 双口 |
| 输入 | 18W Type-C | 22.5W Type-C |
| 重量 | 210g | 430g |
| 是否可登机 | 是 | 是（≤ 100Wh） |

> 充电宝额定能量 = 容量 × 3.7V ÷ 1000。P1 约 37Wh、P2 约 74Wh，均低于 100Wh，可随身携带登机，无需托运。

|------|------|---------|---------|
| Type-C 快充线 | 1m / 2m | PD 100W | 手机、笔记本 |
| Lightning 线 | 1m | 2.4A | iPhone |
| Micro-USB 线 | 1m | 2A | 老款设备/充电宝 |
| 三合一编织线 | 1.2m | 各口 2.4A | 多设备用户 |

## 五、购买建议

- 智能音箱：首次使用需连接家庭 Wi-Fi，配置过程中请保持手机与音箱在同一网络；
- 蓝牙耳机：入耳式请先试戴确认耳塞尺寸，运动场景优先选 IPX5 以上防水等级；
- 充电宝：P1/P2 均可随身携带登机，无需托运申报（≤ 100Wh）；
- 数据线：快充需要「线 + 充电器」同时支持对应协议，单换线无法提升充电速度。
