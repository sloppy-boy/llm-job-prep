# 账号管理说明

本说明覆盖账号登录、绑定手机与账号注销三部分，帮助您安全、顺畅地使用云选商城服务。

## 一、账号登录

### 1.1 支持的登录方式

| 登录方式 | 说明 | 适用场景 |
|---------|------|---------|
| 手机号 + 验证码 | 免密登录，验证码 5 分钟内有效 | 推荐，日常使用 |
| 手机号 + 密码 | 需已设置登录密码 | 无验证码时可使用 |
| 微信授权登录 | 需绑定手机号 | 第三方快捷登录 |
| 支付宝授权登录 | 需绑定手机号 | 第三方快捷登录 |

> 第三方授权登录（微信/支付宝）首次使用会要求绑定手机号，绑定后即可正常购物。

### 1.2 登录异常处理

- 验证码收不到：检查是否被手机拦截；同一手机号 5 分钟内最多发送 5 条，超限请稍后再试；
- 连续输错密码：连续 5 次错误将锁定 15 分钟；
- 异地登录提醒：若收到非本人操作的登录提醒，请立即修改密码并解绑异常设备。

## 二、绑定手机

### 2.1 换绑手机流程

```
登录 → 账号安全 → 换绑手机 → 验证原手机 → 输入新手机 → 完成
```

| 情形 | 操作 |
|------|------|
| 原手机号可正常接收短信 | 按上述流程自助换绑 |
| 原手机号已停用/丢失 | 人工审核：提供账号实名信息 + 历史订单截图 + 本人身份证明，审核 1-3 个工作日 |

### 2.2 注意事项

- 同一手机号 30 天内仅支持换绑 2 次；
- 换绑成功后，原手机号将解绑，可用于注册其他账号；
- 账号涉及未完成的退款、投诉等流程时暂不支持换绑，请处理完毕后再操作。

## 三、账号注销

### 3.1 注销条件

同时满足以下条件方可注销：

- 账号内无进行中的订单、退款、换货或投诉；
- 账号无未结清的账单（白条、待付款订单等）；
- 账号不在注销冷静期内（注销后有 30 天冷静期，期间可随时撤销）。

### 3.2 注销流程与后果

| 步骤 | 说明 |
|------|------|
| 提交申请 | 账号安全 → 注销账号 → 验证身份 |
| 冷静期 | 30 天，期间可撤销注销 |
| 正式注销 | 冷静期满后账号永久关闭 |
| 数据删除 | 注销后个人资料、订单记录、优惠券均不可恢复 |

> 请务必在注销前处理好退款、售后与余额提现。账号一旦正式注销，数据不可找回。

## 四、账号安全建议

- 开启登录保护与支付验证；
- 不向他人透露验证码与支付密码；
- 更换手机号后及时换绑，避免账号被盗用；
- 收到可疑链接或客服来电，先通过官方渠道核实。
