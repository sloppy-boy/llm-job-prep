# 换货规则

换货是指对已签收商品进行同款换新或更换为其他款式。云选商城支持符合条件的换货申请，规则如下。

## 一、换货条件

同时满足以下条件可申请换货：

1. 商品已签收，且签收时间在 15 天内（质量问题不受此限制，但须在保修期内）；
2. 商品外观完好，不影响二次销售（质量问题除外）；
3. 未超出可换货商品范围。

以下情形不支持换货：

- 定制类、鲜活易腐类、个人贴身类商品；
- 已拆封且影响二次销售的影音制品、软件；
- 明显超出 15 天签收期限的非质量问题商品（可走七天无理由或保修流程）。

## 二、换货流程

```
提交换货申请 → 商家审核（48 小时内） → 寄回原商品 → 商家确认收货 → 发出换货商品
```

| 环节 | 时效 |
|------|------|
| 商家审核换货申请 | 提交后 48 小时内 |
| 寄回原商品 | 审核通过后 7 天内 |
| 商家确认收货 | 物流签收后 48 小时内 |
| 发出换货商品 | 确认收货后 48 小时内发出（现货） |

## 三、换货运费

- 换货寄回运费由买家承担，换货发出的运费由商家承担；
- 质量问题换货的往返运费均由卖家承担；
- 运费险适用于换货场景，理赔金额以运费险保单页面展示为准。

## 四、库存无货时的处理

当换货商品暂时无货时，您有以下选择：

| 选项 | 说明 |
|------|------|
| 等待补货 | 可预约缺货登记，到货后系统短信通知，登记 30 天内有效 |
| 更换其他款式 | 差价多退少补，按换货时的实际售价计算 |
| 转为退款 | 原商品寄回确认后按购买金额退款，换货申请自动转为退货退款 |

> 若 30 天内未能补货到货，系统将自动为您转为退款处理，请留意站内消息。

## 五、换货注意事项

- 换货商品不支持再次换货，如仍不满意可走退货退款流程；
- 换货成功后，原订单的保修期自换货商品签收日起重新计算；
- 换货过程中请勿剪断吊牌、丢弃包装，否则可能影响审核结果。
